# 스마트제조 공급기업 역량진단 지표 개선 및 전문기업 지정제도 운영방안

---

## 요약

□ 현행 KTRS-FM 중심 역량진단은 공급기업 간 기술수준 변별이 곤란하므로, 경영(19%)·기술(40%)·PM(41%) 3축 체계로 개편함

□ 역량진단 Level 3(750점) 이상 기업을 전문기업으로 지정하되, 중복심사 없이 역량진단 결과를 일원화 활용함

□ 전문기업 지정이 실효성을 갖추려면 R&D·금융·판로·인력·해외진출·브랜딩 6대 분야 혜택을 동시에 설계해야 하며, 지원사업 성격에 따라 전용·할당·가점·멘토단 방식을 구분 적용함

---

## [Part 1] 역량진단 지표 개선

### 1. 현행 KTRS-FM 중심 평가는 공급기업 간 기술수준 변별이 곤란하여 지표체계 개편이 필요함

○ KTRS-FM은 초기 창업기업 보증심사용 모델로, 대부분 공급기업 점수가 상위에 수렴하여 기술 우열 식별이 어려움
- 기존 평가는 정보화·SW 중심 설계로 자동화기기·연결화기기 등 HW 기반 공급기업 특성이 미반영
- 현장평가 시 평가위원 주관에 따라 결과가 달라질 수 있어 객관성 보완 필요

○ 「스마트제조혁신 촉진법」 시행과 전문기업 지정제도 연계를 위해 스마트제조 특화 기술지표 신설이 필요한 시점임

### 2. KTRS-FM을 경영 기초평가(19%)로 축소하고, 기술(40%)·PM(41%) 특화지표를 신설함

○ 경영(19%) — KTRS-FM으로 기업 기본 안정성만 확인
○ 기술(40%) — 제조자율성 공통지표(Level 0~5) + 자동화·연결화·정보화·지능화 4대 분야별 특화지표
○ PM(41%) — 요구사항 정의~변경관리~품질검증~유지관리까지 PDCA 기반 산출물 중심 평가

| 구분 | 기존 | 개선 |
|---|---|---|
| 경영 | KTRS-FM이 경영·기술 전반 포괄 | 경영 기초체력 확인으로 한정(19%) |
| 기술 | 일반 기술역량, SW 중심 | 제조자율성 + 4대 분야별 특화지표(40%) |
| PM | 구축 과정 일부 항목 | PDCA 전주기 산출물 중심 평가(41%) |
| 증빙 | 서류 중심, 정성 판단 | 시험성적서·로그·산출물·현장시연 |

### 3. 기술지표는 "제조자율성 Level 0~5"로 현장 구현 수준을 구분하고, 분야별 전문성을 별도 평가함

○ 제조자율성은 수동조작(L0)부터 AI 자율운영(L5)까지 6단계로 공급기업의 실제 구현 수준을 판정
- L0 수동조작 → L1 단순자동화 → L2 센서기반 모니터링 → L3 AI 지원(사람이 최종 실행) → L4 AI 자율제어 → L5 에이전틱 자율운영
- 탈락 기준이 아니라 성장경로를 보여주는 진단 기준으로 운영

○ 4대 분야별 특화지표로 분야별 기술 깊이를 확인

| 분야 | 핵심 평가 내용 |
|---|---|
| 자동화 | 구동·측정 정밀도, 현장 최적화, KOLAS 성적서 |
| 연결화 | OPC-UA/MQTT 지원, IEC 62443 보안, 상호운용성 |
| 정보화 | 독자 SW 솔루션, 도메인 최적화, 소스코드 수준 유지보수 |
| 지능화 | AI·디지털트윈 원천기술 보유, 제조 특화 실증성과 |

### 4. 종합등급은 Level 0~5로 산정하며, Level 3 이상을 전문기업 지정 기준선으로 활용함

| 등급 | 점수 | 정책 활용 |
|---|---|---|
| L5 맞춤·자율 | 950+ | 글로벌 선도기업 후보 |
| L4 최적화·통합 | 850~950 | 선도 전문기업군 |
| **L3 분석·제어** | **750~850** | **전문기업 지정 기준선** |
| L2 측정·확인 | 650~750 | 보완 후 진입 가능군 |
| L1 식별·점검 | 550~650 | 기초역량 보완 필요 |
| L0 미적용 | 550 미만 | 진단·컨설팅 우선 대상 |

- 제도 초기에는 파일럿 결과와 기업 분포를 고려하여 경과 기준(650점 이상) 검토 가능

## [Part 2] 전문기업 지정제도

### 5. 전문기업 지정은 역량진단 Level 3 이상 기업을 기준으로 중복심사 없이 일원화 운영함

○ 역량진단에서 경영·기술·PM을 이미 종합평가하므로, 전문기업 지정 시 별도 중복심사를 최소화
- Level 3 이상(750점)은 표준 기반의 안정적 프로젝트 수행 역량을 보유한 기업군
- Level 3 미만 기업에게는 보완과제·컨설팅·재진단을 통한 성장경로 제공

○ 유사 제도 중 지능형로봇 전문기업은 진입요건 과도 + 인센티브 부재로 지정 실적 전무하므로, 진입 가능한 기준과 실효적 혜택을 동시에 설계함

### 6. 지정 프로세스는 6단계로 운영하며, 각 단계별 수행주체·소요기간·산출물을 아래와 같이 구체화함

| 단계 | 내용 | 수행주체 | 소요기간(예상) | 산출물 |
|---|---|---|---|---|
| ① 역량진단 신청 | 온라인 시스템으로 신청, 주력 분야 선택, 경영·기술·PM 증빙자료 제출 | 공급기업 | 상시 접수 | 신청서, 자가진단표, 증빙자료 |
| ② 서면평가 | KTRS-FM 경영평가 + 기술·PM 서면검토, 현장확인 항목 도출 | 수행기관(이노비즈), 기보(KTRS) | 신청 후 2~3주 | 서면평가서, 현장확인 체크리스트 |
| ③ 현장실사 | 기술 구현 수준·산출물 원본·PM 운영체계 현장 확인 | 기술위원 + KTRS위원 (2인 1조) | 1일/기업 | 현장실사 보고서 |
| ④ 종합등급 산정 | AHP 가중치 적용, Level 0~5 산정 | 수행기관 | 현장실사 후 1~2주 | 종합평가 결과서 |
| ⑤ 전문기업 지정·통보 | Level 3 이상 기업 선별, 지정 분야·유효기간 결정, 전문기업 Pool 등록 | 추진단, 심의위원회(필요시) | 등급 산정 후 2~4주 | 지정 통보서, Pool 등록 |
| ⑥ 사후관리·갱신 | 연차 경량점검(인력·만족도·민원), 3년 갱신(재진단 또는 성과점검), 취소·승급·강등 | 추진단, 심의위원회 | 연 1회 점검 / 3년 갱신 | 연차 점검 결과, 갱신 판정서 |

○ ①~⑤까지 신규 지정 소요기간은 약 6~8주(신청 접수 마감 기준)
○ 신청은 연중 상시 접수하되, 평가·지정은 반기 또는 분기 단위로 일괄 처리하는 방식이 행정 효율상 적정

### 7. 심의위원회는 개별기업 재심사가 아닌 기준관리·사후관리 기구로 운영함

| 역할 | 구체적 업무 |
|---|---|
| 기준관리 | 역량진단 지표·가중치·등급구간·증빙기준의 적정성을 연 1회 이상 점검하고 조정안 의결 |
| 예외관리 | 입력자료 오류 정정, 이의신청 심의(기업이 등급에 이의 제기 시 재평가 여부 판단), 특수사례 심의 |
| 사후관리 | 갱신 미달·민원·분쟁 발생 기업에 대한 보완요구·지정유보·지정취소 판단 |
| 성과관리 | 지정기업의 사업 참여 실적, 도입기업 만족도, 지원사업 효과를 연 1회 종합 점검 |

○ 위원 구성: 스마트제조 분야 기술전문가, 정책전문가, 산업계 인사 등 10인 내외
○ 운영 빈도: 정기회의 연 2회(상·하반기 지정 심의) + 수시회의(이의신청·취소 등)

### 8. 전문기업은 4대 공급분야로 지정하되, 기존 산업분류와의 정합성을 확보함

□ 기본 지정축: 자동화기기·연결화기기·정보화솔루션·지능화서비스 4대 분야

○ 이 분류는 스마트제조 정책에서 공급기업의 기술적 역할을 구분하기 위한 특수분류로, 한국표준산업분류(KSIC)와는 분류 기준이 다름

□ 기존 분류체계와의 관계 정리

| 분류체계 | 기준 | 용도 | 스마트제조 4대 분야와의 관계 |
|---|---|---|---|
| 한국표준산업분류(KSIC) | 산업 업종(제조업, 서비스업 등) | 통계, 행정 일반 | 1개 KSIC 코드에 4대 분야 중 복수가 해당될 수 있음 |
| 기술분류(국가과학기술표준분류) | 기술 분야(IT, BT 등) | R&D 과제 관리 | 기술지표의 세부 평가항목과 부분적으로 대응 |
| 공급기업 풀 기존 분류 | 업종·솔루션 유형 | 공급기업 Pool 관리 | 정보화 중심 분류로 자동화·연결화 기업이 분류 사각지대 |
| **스마트제조 4대 분야** | **공급기업의 기술적 역할** | **역량진단·전문기업 지정** | **기존 분류와 별도로 운영하되, 매핑 테이블로 연결** |

○ 4대 분야 분류는 기존 분류를 대체하는 것이 아니라, 역량진단·전문기업 지정 목적의 정책 분류로 병행 운영
- 기존 KSIC·풀 분류 코드는 그대로 유지하고, 4대 분야 코드를 추가 부여
- 기업이 복수 분야에 해당하는 경우 주력 분야 1개를 선택하여 지정하되, 부가 분야를 별도 표기

○ 도입기업 수요 매칭을 위해 업종 레퍼런스 태그(자동차·식품·전자부품 등)를 보조축으로 운영
- 도입기업은 "자동화기기 분야 + 식품제조업 레퍼런스"처럼 분야와 업종을 조합하여 공급기업 검색 가능

□ 분류 간 매핑 예시

| 기업 예시 | KSIC | 기존 풀 분류 | 4대 분야(주력) | 4대 분야(부가) | 업종 레퍼런스 |
|---|---|---|---|---|---|
| PLC·로봇 통합 자동화 기업 | C29(기타 기계·장비) | 자동화설비 | 자동화기기 | 연결화기기 | 자동차, 전자부품 |
| MES·ERP 솔루션 기업 | J62(SW개발·공급) | 정보화솔루션 | 정보화솔루션 | - | 식품, 화학 |
| AI 품질검사 스타트업 | J62(SW개발·공급) | 정보화솔루션 | 지능화서비스 | 정보화솔루션 | 반도체, 디스플레이 |
| 산업용 IoT 게이트웨이 기업 | C26(전자부품·컴퓨터) | 통신장비 | 연결화기기 | - | 금속, 기계 |

### 9. 유효기간은 3년으로 하고, 연차 경량점검 + 3년 갱신으로 사후관리함

| 구분 | 내용 |
|---|---|
| 유효기간 | 3년 |
| 연차 점검 | 인력 이탈, 만족도, 실적, 민원·분쟁 여부 경량 점검 |
| 3년 갱신 | 재진단 또는 성과점검으로 Level 3 이상 유지 확인 |
| 기준 미달 | 보완요구 → 지정 유보 → 지정 취소 순차 적용 |
| 우수기업 | 선도 전문기업군 승급 가능 |

### 10. 혜택은 6대 분야 패키지로 설계하며, 사업 성격별로 전용·할당·가점·멘토단 방식을 구분 적용함

○ 6대 분야 혜택

| 분야 | 주요 혜택 |
|---|---|
| R&D | 전문기업 전용 R&D 과제, 자율형공장·클라우드화·종합솔루션화 연계 |
| 금융 | 정책자금 우대, 보증료 감면, 스마트제조 전용 보증 |
| 판로·공공조달 | 고도화 과제 전문기업 참여, 공공 발주 가점 |
| 인력 | 산업기능요원 가점, 전문인력 매칭, 재직자 교육 |
| 해외진출 | 수출바우처, 해외규격인증, 해외 PoC·실증 |
| 브랜딩·매칭 | 전문기업 명패, 우수기업 공개, 도입기업 매칭 플랫폼 |

○ 지원사업 내 4가지 인센티브 방식

| 방식 | 적용 대상 |
|---|---|
| 전용(전문기업만 참여) | 자율형공장, 클라우드화, 종합솔루션화 등 고도화 사업 |
| 할당 확대(비율 단계적 확대) | 정부일반형 고도화, 디지털협업공장, 탄소중립형 등 |
| 가점(선정평가 시 가점) | 제조로봇활용, 데이터가공 등 |
| DX멘토단 우선참여 | 사전기획, 구축지도, 사후관리 |

○ 성장사다리 3단계(소부장법 벤치마킹)
- 1단계(역량진단 우수기업): 컨설팅, 교육, 기술혁신 바우처
- 2단계(스마트제조 전문기업): 전용·할당 사업, 정책자금, R&D, 멘토단
- 3단계(글로벌 전문기업): 자율 R&D, 해외 PoC, 글로벌 IR, 대형 프로젝트 우선참여
