# 스마트제조 전문기업 지정제도 운영방안

## 1. 도입기업이 공급기업 역량을 사전에 파악하기 어려워 고도화 과제의 비용·일정·품질 리스크가 확대되고 있으므로, 전문기업 지정제도를 통해 검증된 공급기업 Pool을 구축할 필요가 있음

□ 도입기업은 공급기업의 기술수준·공정 이해도·PM역량·유지보수 역량을 사전에 알기 어려움

○ 공급기업은 가격 중심 경쟁 구조 속에서 기술투자 여력이 약화되는 악순환 지속
○ 전문기업 지정제도는 도입기업에게 검증된 공급기업 Pool을, 공급기업에게 역량 중심 경쟁 기반을 제공하는 공공 인증 체계임

□ 국내 유사 제도 중 활성화된 제도는 실효적 인센티브를, 비활성화 제도는 과도한 기준과 인센티브 부재가 원인임

| 제도 | 핵심 요인 | 시사점 |
|---|---|---|
| 뿌리기술 전문기업 | 정책자금·인력·공정혁신 등 실질 인센티브 → 활성화 | 혜택 패키지 동시 설계 필수 |
| 소부장 전문기업·으뜸기업 | 성장사다리 + 범부처 지원 → 활성화 | 단계적 성장경로 필요 |
| 정보보호 전문서비스 | 법적 지위 → 사업 수행 자격 부여 → 활성화 | 법적 지위·수주 연계 검토 |
| 지능형로봇 전문기업 | 과도한 진입요건 + 인센티브 부재 → 지정 실적 전무 | 진입 가능 기준 + 실질 혜택 동시 필요 |

---

## 2. 전문기업 지정은 역량진단 Level 3 이상 기업을 기준으로 중복심사 없이 일원화 운영하며, 심의위원회는 기준관리·사후관리를 담당함

### 2-1. 지정 프로세스: 역량진단 결과 기반 6단계 운영

○ 역량진단에서 경영(19%)·기술(40%)·PM(41%)을 이미 종합평가하므로, 전문기업 지정 시 별도 중복심사를 최소화하여 기업·행정 부담 경감

| 단계 | 내용 |
|---|---|
| ① 역량진단 신청 | 온라인 시스템 신청, 경영·기술·PM 증빙자료 제출 |
| ② 서면평가·현장확인 | KTRS-FM·기술지표·PM지표 평가, 현장 실사 |
| ③ 종합등급 산정 | AHP 가중치 기반 Level 0~5 산정 |
| ④ Level 3 이상 선별 | 전문기업 지정 대상 분류(기준선 750점) |
| ⑤ 지정·통보 | 지정 분야·유효기간 통보, 전문기업 Pool 등록 |
| ⑥ 사후관리·갱신 | 연차 경량점검, 3년 갱신, 취소·승급·강등 |

### 2-2. 지정 기준선

○ Level 3(750점) 이상은 표준 기반의 안정적 스마트제조 프로젝트 수행 역량을 보유한 기업군
○ Level 3 미만 기업에게는 보완과제·컨설팅·재진단을 통한 성장경로 제공
○ 제도 초기에는 파일럿 결과와 기업 분포를 고려하여 경과 기준(650점 이상) 검토 가능

### 2-3. 심의위원회: 개별 재심사가 아닌 기준관리·사후관리 기구로 운영

| 역할 | 내용 |
|---|---|
| 기준관리 | 역량진단 지표, 가중치, 등급구간, 증빙기준 적정성 점검 |
| 예외관리 | 입력자료 오류, 평가결과 정정, 이의신청, 특수사례 심의 |
| 사후관리 | 갱신, 취소, 보완요구, 등급조정 기준 운영 |
| 성과관리 | 지정기업 성과, 도입기업 만족도, 지원사업 효과 점검 |

- 심의위원회가 모든 기업을 재심사하는 병목이 되지 않도록 설계

### 2-4. 유형화: 4대 공급분야 지정 + 도입업종 레퍼런스 태그 병행

○ 자동화기기·연결화기기·정보화솔루션·지능화서비스 4대 분야를 기본 지정축으로 설정
- 지표체계와 정합되며, 분야별 기술육성 방향이 명확함
○ 도입기업 수요 매칭을 위해 업종 레퍼런스 태그(자동차·식품·전자부품 등)를 보조축으로 운영

### 2-5. 유효기간 3년, 연차 경량점검 + 3년 갱신 체계

| 구분 | 내용 |
|---|---|
| 유효기간 | 3년 원칙 |
| 연차 점검 | 인력 이탈, 만족도, 실적, 민원·분쟁 여부 경량 점검 |
| 3년 갱신 | 재진단 또는 성과점검으로 Level 3 이상 유지 확인 |
| 기준 미달 | 보완요구 → 지정 유보 → 지정 취소 순차 적용 |
| 우수기업 | 선도 전문기업군 승급 가능 |

- 1년은 혜택 체감에 짧고, 5년 이상은 기술 변화 속도 대비 역량 유지 확인이 곤란하여 3년이 적정

## 3. 혜택은 R&D·금융·판로·인력·해외진출·브랜딩 6개 분야 패키지로 설계하며, 사업 성격별로 전용·할당·가점·멘토단 방식을 구분 적용함

### 3-1. 6대 분야 혜택 패키지

| 분야 | 주요 혜택 |
|---|---|
| R&D | 전문기업 전용 R&D 과제, 자율형공장·클라우드화·종합솔루션화 과제 연계 |
| 금융 | 정책자금 우대, 보증료 감면, 스마트제조 전용 보증 |
| 판로·공공조달 | 고도화 과제 전문기업 참여, 공공 발주 가점 또는 자격 |
| 인력 | 산업기능요원 가점, 전문인력 매칭, 재직자 교육 |
| 해외진출 | 수출바우처, 해외규격인증, 해외 PoC·실증, 바이어 매칭 |
| 브랜딩·매칭 | 전문기업 명패·지정서, 우수기업 공개, 도입기업 매칭 플랫폼 |

### 3-2. 스마트제조혁신 지원사업 내 4가지 인센티브 방식

| 방식 | 개념 | 적용 대상 |
|---|---|---|
| 전용 | 전문기업만 참여 가능 | 자율형공장, 클라우드화, 종합솔루션화 등 고도화 사업 |
| 할당 확대 | 전문기업 참여 비율 단계적 확대(15%→30% 등) | 정부일반형 고도화, 디지털협업공장, 탄소중립형 등 |
| 가점 | 선정평가 시 전문기업 가점 | 제조로봇활용, 데이터가공 등 |
| DX멘토단 우선참여 | 전문기업 멘토단 우선 배치 | 사전기획, 구축지도, 사후관리 |

- 전용 방식이 참여유인이 가장 강하나 초기에는 대상 사업을 제한적으로 적용
- 가점만으로는 참여유인이 약하므로 보조수단으로 활용

### 3-3. 성장사다리 3단계(소부장법 벤치마킹)

| 단계 | 대상 | 주요 지원 |
|---|---|---|
| 1단계 역량진단 우수기업 | Level 2~3 진입 가능군 | 컨설팅, 교육, 기술혁신 바우처, 일반 보급사업 참여 |
| 2단계 스마트제조 전문기업 | Level 3 이상 지정기업 | 전용·할당 사업, 정책자금 우대, R&D, 멘토단, 브랜딩 |
| 3단계 글로벌 전문기업 | Level 4 이상 또는 성과 우수 | 자율 R&D, 해외 PoC, 글로벌 IR, 대형 프로젝트 우선참여 |
| 보완군 | Level 3 미만 또는 갱신 미달 | 보완과제, 재진단, 역량개선 프로그램 |

### 3-4. 추진 시기별 구분

| 시기 | 추진 가능 혜택 | 비고 |
|---|---|---|
| 단기 | 명패·지정서, 우수기업 공개, 도입기업 매칭, DX멘토단 우선참여, 일부 가점 | 법령·예산 부담 낮음 |
| 중기 | 고도화 과제 전용·할당, 정책자금 우대, 전문기업 전용 R&D 일부 도입 | 지정 체감효과의 핵심 구간 |
| 장기 | 산업기능요원 가점, 세제지원, 해외 실증, 글로벌 전문기업 패키지 | 관계부처 협의·법령 기반 필요 |

## 4. 기대효과

| 대상 | 효과 |
|---|---|
| 도입기업 | 공급기업 분야·기술수준·PM역량 사전 확인 → 실패위험 감소, 탐색비용 절감 |
| 공급기업 | 가격 경쟁에서 기술·품질 중심 경쟁으로 전환, 전문기업 지정을 통한 성장기회 확보 |
| 정부 | 공급기업 Pool을 분야별·수준별 정책관리 대상으로 전환, 고도화 과제 품질 향상 |

## 5. 단계별 추진전략

### Step 1. 기반 구축
○ 역량진단 지표 확정 및 파일럿 검증
○ 온라인 신청·자가진단 시스템 구축
○ 지정 기준, 유효기간, 갱신·취소 기준 마련
○ 심의위원회 구성 및 운영규정 정비
○ 법령 또는 고시 반영 필요사항 검토

### Step 2. 활성화
○ 전문기업 지정 시범 운영
○ 전문기업 Pool 공개 및 도입기업 매칭
○ 고도화 과제 내 전용·할당·가점 시범 적용
○ DX멘토단 우선참여 운영
○ 정책자금·R&D·수출지원 연계 협의

### Step 3. 고도화
○ 선도 전문기업군·집중지원군 층화 운영
○ 성과 기반 승급·강등·취소 운영
○ 해외 PoC, 글로벌 IR, 해외 테스트베드 연계
○ 전문기업 성과 모니터링 및 정책효과 분석

## 6. 향후 과제

○ 관계부처(산업부·과기정통부·기재부 등) 협의체 구성, 시범 사업 우선 적용 후 점진적 확대
○ 역량진단-전문기업 지정-도입기업 매칭 연계 전략 추가 보완(향후 작성예정)
○ 법 제정 전에는 "지정 예정 대상"으로 통보, 법적 근거 정비 후 장관 명의 지정서 발급 추진
