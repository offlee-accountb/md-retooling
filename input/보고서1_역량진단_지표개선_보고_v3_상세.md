# 스마트제조 공급기업 역량진단 지표 개선 방안

## 1. 현행 KTRS-FM 중심 평가는 공급기업 간 기술수준 변별이 곤란하여 지표체계 개편이 필요함

□ 스마트공장 3만 개 구축 이후 고도화 단계에서는 공급기업의 기술·PM·유지보수 역량이 사업성과를 좌우하나, 현행 평가체계는 이를 식별하기 어려움

○ 중소 제조기업은 AI·데이터·자동화·통신표준 역량을 자체 내재화하기 어려워 공급기업 의존도가 높음
- 고도화 단계에서 공급기업 역량 차이가 도입기업의 구축 성패를 직접 결정
- 「스마트제조혁신 촉진법」 시행에 따라 역량평가 강화 및 전문기업 지정제도 연계 기반이 마련된 시점임

□ KTRS-FM은 초기 창업기업 보증심사용 모델로, 스마트제조 공급기업 역량진단 목적과 괴리가 존재함

| 구분 | 한계 | 실제 영향 |
|---|---|---|
| 변별력 | KTRS-FM 점수가 대부분 상위에 수렴 | 우수기업과 미흡기업 구분 곤란 |
| 객관성 | 현장평가가 평가위원 주관에 좌우될 가능성 | 평가자에 따라 결과 편차 발생 |
| 포괄성 | 정보화·SW 중심 설계로 HW 기반 기업 특성 미반영 | 자동화·연결화 기업이 구조적으로 과소평가 |

## 2. KTRS-FM은 경영 기초평가(19%)로 축소하고, 스마트제조 특화 기술지표(40%)와 PM지표(41%)를 신설함

□ 평가의 중심을 "일반 기업평가"에서 "스마트제조 현장 수행역량 진단"으로 전환함

○ KTRS-FM은 재무 안정성·경영진 역량·시장 대응력 등 경영 기초체력 확인 기능으로 한정
○ 기술 영역에 제조자율성 공통지표 + 4대 분야별 특화지표를 신설
○ PM 영역에 PDCA 기반 산출물 중심 프로젝트 관리체계 평가를 신설

□ 기존·개선 체계 비교

| 구분 | 기존 | 개선 |
|---|---|---|
| 경영 | KTRS-FM이 경영·기술 전반 포괄 | 경영 기초체력 확인으로 한정(19%) |
| 기술 | 일반 기술역량, SW 중심 | 제조자율성 + 4대 분야별 특화지표(40%) |
| PM | 구축 과정 일부 항목 | PDCA 전주기 산출물 중심 평가(41%) |
| 증빙 | 서류 중심, 정성 판단 | 시험성적서·로그·산출물·현장시연 |
| 결과 활용 | 우수기업 식별 | 등급화, 개선 권고, 전문기업 지정, 지원사업 연계 |

□ 전체 평가 구조

| 대분류 | 중분류 | 핵심 내용 | 평가 방식 |
|---|---|---|---|
| 경영 | 경영주역량, 기술성, 시장·사업성 | 재무 안정성, 경영진 역량, 시장 대응력 | KTRS-FM 활용 |
| 기술 | 제조자율성 | 수동조작~AI 자율운영까지 기술 수준 판정 | Level 0~5 공통 기준 |
| 기술 | 부문별 특화지표 | 자동화·연결화·정보화·지능화 분야별 전문성 | 분야별 증빙자료·현장확인 |
| 기술 | 데이터 활용 | 제조 데이터 생애주기 관리 및 AI 큐레이션 역량 | 증빙자료·시스템 확인 |
| PM | 프로젝트 기획 | 요구사항 정의, 역량 분석, 범위·일정 수립 | 산출물·현장확인 |
| PM | 프로젝트 수행·관리 | 변경관리, 리스크관리, 품질보증 | 산출물·로그·회의록 |
| PM | 성과·유지관리 | 성과 측정, 인계·교육, 사후관리, 지식자산화 | 성과보고서·매뉴얼·이슈로그 |
| 가점 | 성장성·고객신뢰·혁신 | 수출금액, 만족도, 인력 안정성, R&D 투자비율 | 보완 지표 |

## 3. 기술지표는 제조자율성(Level 0~5)으로 현장 구현 수준을 공통 판정하고, 4대 분야별 특화지표로 기술 깊이를 확인함

□ 제조자율성 공통지표는 공급기업의 시스템·장비·솔루션이 데이터 기반으로 판단·제어·최적화를 어디까지 수행하는지 판정하는 기준임

| Level | 수준 | 내용 |
|---|---|---|
| 0 | 수동조작 | 모든 작업이 작업자 수동 조작에 의해 수행 |
| 1 | 단순 자동화·디지털 복제 | 고정 로직에 따라 사전 프로그래밍된 작업을 반복 |
| 2 | 센서 기반 모니터링 | 센서·설비 데이터를 수집하여 실시간 모니터링·알람 |
| 3 | 분석·AI 지원 | AI가 판단·추천하나 최종 실행은 작업자가 수행 |
| 4 | AI 자율제어 | AI 판단이 작업자 승인 없이 공정 파라미터에 자동 반영 |
| 5 | 에이전틱 자율운영 | AI 에이전트가 목표를 해석하고 세부작업을 자율 계획·실행·학습 |

- Level 5를 모든 기업에 요구하는 것이 아니라, 현재 수준을 확인하고 다음 단계 보완과제를 도출하는 진단 기준으로 운영

□ 4대 분야별 특화지표는 분야별 고유 기술의 성능·신뢰성·독자성·현장 적용성을 확인함

| 분야 | 핵심 평가 내용 | 대표 증빙자료 |
|---|---|---|
| 자동화 | 구동·측정 정밀도, 현장 최적화, 안정성 | 장비 사양서, KOLAS 성적서, 정밀도 시험자료, 현장 실증 리포트 |
| 연결화 | 상호운용성, 통신표준(OPC-UA/MQTT), OT 보안(IEC 62443) | 통신 인터페이스 명세서, 보안 인증자료, 네트워크 구성도 |
| 정보화 | 독자 솔루션 보유, 핵심 제조 로직 자체 개발, 도메인 최적화 | SW 아키텍처, 저작권·특허, API 명세, 구축성과 자료 |
| 지능화 | AI·빅데이터·디지털트윈 원천기술의 우수성과 제조 도메인 적용 실적 | AI 모델 성능자료, 알고리즘 설명서, 실증성과, 해외 벤치마크 |

- HW 기업(자동화·연결화)은 장비 정밀도·통신표준·보안으로, SW 기업(정보화·지능화)은 솔루션 독자성·알고리즘 성능으로 각각 평가
- 단순 "AI 보유 여부"가 아니라 알람 수준인지, 최적안 추천인지, 자동 반영인지를 구분하여 고도화 역량 식별

## 4. PM지표는 PDCA 기반 산출물 중심 평가로 개편하여, 프로젝트를 반복적으로 성공시킬 수 있는 관리체계를 확인함

□ 도입기업 불만은 대부분 기술 자체보다 요구사항 불일치·일정 지연·유지보수 불안에서 발생하므로, PM 평가는 이러한 실패요인을 사전에 줄이는 관리체계 확인에 초점을 둠

| 단계 | 세부 평가항목 | 확인 내용 | 대표 증빙자료 |
|---|---|---|---|
| 기획(Plan) | 요구사항 정의 | 도입기업 요구를 수행 가능한 요구사항으로 구조화·합의 | 요구사항 정의서, RFP 대응표, 승인 기록 |
| 기획(Plan) | 내·외부 역량 분석 | 내부 수행과 외주 범위를 합리적으로 구분 | 조직도, 투입인력표, R&R, 외주계획 |
| 기획(Plan) | 범위 설정·실행계획 | WBS, 일정, 성과목표를 구체화 | 사업계획서, WBS, KPI, 범위 정의서 |
| 수행(Do) | 통합관리·통제 | 계획 대비 실적·변경사항을 공식 절차로 관리 | 변경관리대장, 주간보고서, Plan vs Actual |
| 수행(Do) | 이슈·리스크 관리 | 잠재 위험을 사전 식별·우선순위화·모니터링 | 이슈대장, 리스크대장, 대응계획 |
| 수행(Do) | 산출물 품질보증 | 요구사항이 산출물에 오차 없이 구현되었는지 검증 | 테스트 시나리오, RTM, UAT 결과서 |
| 성과(Check·Act) | 성과관리 | 구축 성과를 시스템 원천 데이터로 검증 | 성과보고서, KPI 달성자료, 검수확인서 |
| 성과(Check·Act) | 공식 종료·사후관리 | 교육, 매뉴얼, 초기 안정화 지원 제공 | 매뉴얼, 교육자료, 장애처리 이력 |
| 성과(Check·Act) | 지식자산화 | 프로젝트 경험이 조직 자산으로 공유·표준화 | 표준 템플릿, 공통모듈, 내부 공유자료 |

- PM 지표는 문서량을 보는 것이 아니라, 요구사항 정의→변경관리→품질검증→유지관리까지 반복 가능한 수행체계를 갖추었는지 확인하는 장치임

## 5. AHP 분석 결과 기술(40%)·PM(41%)의 비중을 경영(19%)보다 높게 설정하였으며, 종합등급은 Level 0~5로 산정함

□ 전문가 14인 AHP 가중치

| 평가영역 | 가중치 | 세부 구성 |
|---|---|---|
| 경영역량 | 19.18% | 경영주역량 6.65% + 기술성 5.68% + 시장·사업성 6.85% |
| 기술역량 | 40.15% | 제조자율성 20.27% + 부문별 특화 19.88% |
| PM역량 | 40.66% | 기획 15.38% + 수행·관리 16.86% + 성과·유지 8.41% |

□ 종합등급 체계 및 전문기업 지정 기준선

| 등급 | 의미 | 점수 | 정책 활용 |
|---|---|---|---|
| L5 | 맞춤·자율 | 950+ | 글로벌 선도기업 후보 |
| L4 | 최적화·통합 | 850~950 | 선도 전문기업군 |
| **L3** | **분석·제어** | **750~850** | **전문기업 지정 기준선** |
| L2 | 측정·확인 | 650~750 | 보완 후 진입 가능군 |
| L1 | 식별·점검 | 550~650 | 기초역량 보완 필요 |
| L0 | 미적용 | 550 미만 | 진단·컨설팅 우선 대상 |

- 종합점수는 세부지표 Level 값을 100점 기준으로 환산 후 AHP 가중치를 적용하여 1,000점 만점으로 산정
- Level 3 이상을 전문기업 지정 기준선으로 운영하되, 제도 초기에는 파일럿 결과를 고려하여 경과 기준(650점 이상) 검토 가능

## 6. 역량진단은 5단계 절차로 운영하며, 진단 결과를 전문기업 지정·맞춤형 지원과 연계함

| 단계 | 주요 내용 |
|---|---|
| ① 신청·서면자료 제출 | 공급기업이 온라인 시스템으로 신청, 주력 분야 선택, 자가진단·증빙자료 제출 |
| ② 사전 서면평가 | 경영·기술·PM 자료 검토, 현장확인 항목 도출 |
| ③ 현장실사 | 기술 구현 수준, 산출물 원본, PM 운영체계 현장 확인 |
| ④ 종합판정·결과 교부 | 점수·등급·강약점·개선과제 포함 결과보고서 제공 |
| ⑤ 정책연계 | 전문기업 지정, 우수기업 공개, R&D·컨설팅·인력지원 연계 |

□ 기대효과

| 대상 | 효과 |
|---|---|
| 도입기업 | 공급기업 기술수준·PM역량 사전 확인 → 탐색비용 절감, 구축 실패위험 감소 |
| 공급기업 | 기술·품질 중심 경쟁 전환, 전문기업 지정·지원사업 연계를 통한 성장경로 확보 |
| 정부 | 공급기업 Pool의 분야별·수준별 질적 관리, 고도화 정책 대상 식별 |

## 7. 향후 계획

○ 파일럿 검증 완료 후 등급구간·증빙부담 조정
○ 소규모 기업·복수 분야 기업·인접 사업(스마트공방 등) 적용 방안 추가 검토
○ 데이터 활용 지표 세부 평가문항 보완(향후 작성예정)
○ 도입기업-전문기업 매칭 운영체계 설계(향후 작성예정)
