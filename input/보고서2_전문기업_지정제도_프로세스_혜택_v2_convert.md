<주제목> 스마트제조 전문기업 지정제도 운영방안

□ 전문기업 지정은 역량진단 Level 3 이상 기업을 기준으로 중복심사 없이 일원화 운영함

 ◦ 역량진단에서 경영·기술·PM을 이미 종합평가하므로, 전문기업 지정 시 별도 중복심사를 최소화
   - Level 3 이상(750점)은 표준 기반의 안정적 프로젝트 수행 역량을 보유한 기업군에 해당
   - Level 3 미만 기업에게는 보완과제·컨설팅·재진단을 통한 성장경로 제공
   - 제도 초기에는 파일럿 결과를 고려하여 경과 기준(650점 이상) 검토 가능

 ◦ 유사 제도 중 지능형로봇 전문기업은 진입요건이 과도하고 인센티브가 약해 지정 실적이 전무하므로, 스마트제조는 진입 가능한 기준과 실효적 혜택을 동시에 설계해야 함

□ 지정 프로세스는 6단계로 운영하며, 심의위원회는 개별 재심사가 아닌 기준관리·사후관리를 담당함

<표 제목: 지정 프로세스는 6단계로 운영하며, 심의위원회는 개별 재심사가 아닌 기준관리·사후관리를 담당함>
| 단계 | 내용 |
| --- | --- |
| ① 역량진단 신청 | 온라인 시스템 신청, 경영·기술·PM 증빙자료 제출 |
| ② 서면평가·현장확인 | KTRS-FM·기술지표·PM지표 평가 및 현장 실사 |
| ③ 종합등급 산정 | AHP 가중치 기반 Level 0~5 산정 |
| ④ Level 3 이상 선별 | 전문기업 지정 대상 분류 |
| ⑤ 지정·통보 | 지정 분야·유효기간 통보, 전문기업 Pool 등록 |
| ⑥ 사후관리·갱신 | 연차 경량점검, 3년 갱신, 취소·승급·강등 |

 ◦ 심의위원회는 모든 기업을 재심사하는 병목이 아니라, 등급구간·가중치 적정성 점검, 이의신청, 갱신·취소 기준 운영 등 제도 신뢰성을 유지하는 운영관리 기구로 기능
 ◦ 유효기간은 3년 원칙(1년은 혜택 체감에 짧고, 5년은 기술 변화 대비 곤란)
 ◦ 전문기업 유형화는 4대 공급분야(자동화·연결화·정보화·지능화) 지정 + 도입업종 레퍼런스 태그 병행

□ 혜택은 R&D·금융·판로·인력·해외진출·브랜딩 6개 분야 패키지로 설계하되, 사업 성격에 따라 전용·할당·가점·멘토단 방식을 구분 적용함

   - 3단계(글로벌 전문기업): 자율 R&D, 해외 PoC, 글로벌 IR, 대형 프로젝트 우선참여
