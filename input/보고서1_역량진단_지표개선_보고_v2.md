# 스마트제조 공급기업 역량진단 지표 개선 방안

## 1. 현행 KTRS-FM 중심 평가는 공급기업 간 기술수준 변별이 곤란하여 지표체계 개편이 필요함

○ KTRS-FM은 초기 창업기업 보증심사용 모델로, 대부분 공급기업 점수가 상위에 수렴하여 기술 우열 식별이 어려움
- 기존 평가는 정보화·SW 중심 설계로 자동화기기·연결화기기 등 HW 기반 공급기업 특성이 미반영
- 현장평가 시 평가위원 주관에 따라 결과가 달라질 수 있어 객관성 보완 필요

○ 「스마트제조혁신 촉진법」 시행과 전문기업 지정제도 연계를 위해 스마트제조 특화 기술지표 신설이 필요한 시점임

## 2. 개편 핵심은 KTRS-FM을 경영 기초평가로 축소하고, 기술·PM 특화지표를 신설하는 것임

○ 경영(19%) — KTRS-FM으로 기업 기본 안정성만 확인
○ 기술(40%) — 제조자율성 공통지표(Level 0~5) + 자동화·연결화·정보화·지능화 4대 분야별 특화지표
○ PM(41%) — 요구사항 정의~변경관리~품질검증~유지관리까지 PDCA 기반 산출물 중심 평가

| 구분 | 기존 | 개선 |
|---|---|---|
| 경영 | KTRS-FM이 경영·기술 전반 포괄 | 경영 기초체력 확인으로 한정(19%) |
| 기술 | 일반 기술역량, SW 중심 | 제조자율성 + 4대 분야별 특화지표(40%) |
| PM | 구축 과정 일부 항목 | PDCA 전주기 산출물 중심 평가(41%) |
| 증빙 | 서류 중심, 정성 판단 | 시험성적서·로그·산출물·현장시연 |

## 3. 기술지표는 "제조자율성 Level 0~5"로 현장 구현 수준을 구분하고, 분야별 전문성을 별도 평가함

○ 제조자율성은 수동조작(L0)부터 AI 자율운영(L5)까지 6단계로 공급기업의 실제 구현 수준을 판정
- L0 수동조작 → L1 단순자동화 → L2 센서기반 모니터링 → L3 AI 지원(사람이 최종 실행) → L4 AI 자율제어 → L5 에이전틱 자율운영
- 탈락 기준이 아니라 성장경로를 보여주는 진단 기준으로 운영

○ 4대 분야별 특화지표로 분야별 기술 깊이를 확인

| 분야 | 핵심 평가 내용 |
|---|---|
| 자동화 | 구동·측정 정밀도, 현장 최적화, KOLAS 성적서 |
| 연결화 | OPC-UA/MQTT 지원, IEC 62443 보안, 상호운용성 |
| 정보화 | 독자 SW 솔루션, 도메인 최적화, 소스코드 수준 유지보수 |
| 지능화 | AI·디지털트윈 원천기술 보유, 제조 특화 실증성과 |

## 4. 종합등급은 Level 0~5로 산정하며, Level 3 이상을 전문기업 지정 기준선으로 활용함

| 등급 | 점수 | 정책 활용 |
|---|---|---|
| L5 맞춤·자율 | 950+ | 글로벌 선도기업 후보 |
| L4 최적화·통합 | 850~950 | 선도 전문기업군 |
| **L3 분석·제어** | **750~850** | **전문기업 지정 기준선** |
| L2 측정·확인 | 650~750 | 보완 후 진입 가능군 |
| L1 식별·점검 | 550~650 | 기초역량 보완 필요 |
| L0 미적용 | 550 미만 | 진단·컨설팅 우선 대상 |

- 제도 초기에는 파일럿 결과와 기업 분포를 고려하여 경과 기준(650점 이상) 검토 가능

## 5. 향후 계획

○ 지표 파일럿 검증 완료 후 등급구간·증빙부담 추가 조정
○ 역량진단 결과를 전문기업 지정·맞춤형 지원사업과 연계하여 공급기업 성장 인프라로 운영
○ 소규모 기업·복수 분야 기업·인접 사업(스마트공방 등) 적용 방안 추가 검토
