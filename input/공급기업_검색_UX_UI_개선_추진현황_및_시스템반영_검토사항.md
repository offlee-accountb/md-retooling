# 공급기업 검색 UX/UI 개선 추진현황 및 시스템 반영 검토사항

글로벌AI전문기업실 ｜ 2026. 5.

---

## □ 추진 배경

○ 스마트공장 사업관리시스템 내 공급기업 검색 기능에 대해 두 가지 개선이 요구됨
  - (UX/UI) 검색 결과의 가독성·활용성 향상을 위한 화면 구조 개편
  - (솔루션 검색) 단순 키워드 검색에서 업종·공정·솔루션 기준 탐색형 검색으로 전환

○ 당실은 '25년 하반기부터 UX/UI 디자인 용역 및 솔루션 태깅 체계 기초연구를 수행하여 기획 기반을 마련하였으며, 시스템 반영을 위한 후속 개발공정 전환이 필요한 단계임

### (2) 솔루션 태깅 체계 기초연구 및 ISP 이관

○ '26년 3월, 솔루션 기반 검색 전환을 위한 LLM 기반 2-Layer 태깅 구조 설계 및 파일럿 테스트 수행
  - 공급기업 일상 언어 등록 → 시스템 내부 8차원 56개 태그 자동 변환 → 도입기업 일상 질문 검색 구조
  - 실제 솔루션 등록 데이터·완료보고서 PDF 등으로 검증, 파일럿 기준 약 75% 수준의 태깅 일치율 확인
  - 담당 사무관에게 파일럿 결과 1차 공유 완료

○ 추진단 내부 협의를 통해 솔루션 검색 시스템은 **차세대 사업관리시스템 ISP 용역의 파일럿 과제로 편입**하기로 결정
  - 파일럿 테스트 데이터 및 연구자료 일체를 AI데이터실에 이관 완료, ISP 용역사에 전달하여 차세대 시스템 반영 방향 협의 중

## □ 현안 및 제약사항

○ (퍼블리싱 공정) 유클리드소프트 확인 결과, UX/UI 시스템 반영을 위해서는 디자인 → **CSS 퍼블리싱** → 개발(데이터 연결) 3단계 공정 중 퍼블리싱 소스 확보가 선행되어야 함
  - CSS 퍼블리싱은 기획이 아닌 개발 영역에 해당하며, 시스템 관리 주체인 정보화지원실 주관이 업무 분장상 적절

○ (계약 제약) 기존 수행업체(인더엑스)와 퍼블리싱 추가 수행 가능성을 협의하였으나, 계약 추진상 제약요인이 확인되어 즉시 발주에는 한계가 있었음

○ (업무 분장) 당실은 기획 영역(디자인 개선안, 태깅 체계 설계, 검색 기준 정의)을 수행하였으며, 개발 반영은 아래와 같이 역할 구분이 필요

| 구분 | 기획(당실 수행 완료) | 개발(정보화지원실 수행 필요) |
|---|---|---|
| UX/UI | 화면 구성, 표시 항목, 기능 정의 | CSS 퍼블리싱, UI 구현, 시스템 반영 |
| 솔루션 검색 | 태그 분류체계, 검색 기준, 노출 정책 | 데이터 추출·매핑, DB 반영, 검색 로직 |

## □ 향후 추진방향

○ 현행 시스템과 차세대 시스템의 역할을 구분하여 중복 개발을 방지하는 방향이 적절

| 구분 | 방향 |
|---|---|
| **현행 시스템** | 기 확보된 UX/UI 디자인 개선안 중심으로 검색 결과 화면 개선 우선 적용 |
| **차세대 시스템** | 솔루션 태깅 기반 검색 구조는 ISP 과제와 연계하여 반영 |
| **당실** | 기획안·디자인 산출물 제공 및 개발 과정 협의 지원 |
| **정보화지원실** | CSS 퍼블리싱·개발·시스템 반영 주관 |

○ 인더엑스 측은 기존 디자인 프레임 내에서 항목·키워드 변경이 가능함을 확인하였으며, 기획 자료는 개발 착수 시 즉시 제공 가능한 상태

---

## □ 검토 요청사항

**1.** UX/UI 개선안의 시스템 반영을 위한 CSS 퍼블리싱 및 개발 적용을 **정보화지원실 주관으로 추진** 검토

**2.** 기존 디자인 산출물은 당실에서 제공하고, 화면 구성·표시항목·검색기준 등 기획 사항은 개발 과정에서 협의 지원

**3.** 솔루션 태깅 검색 기능은 차세대 사업관리시스템 ISP 과제로 연계하여 중복 개발 방지

**4.** 현행 시스템에는 UX/UI 개선 범위를 우선 적용하고, 차세대 시스템에 솔루션 기반 검색 구조를 반영하는 단계적 추진
