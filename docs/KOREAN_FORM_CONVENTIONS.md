# 한국 공문서 HWPX 양식 — 입력란 패턴 관례

> 이 문서는 한국 정부/공공기관 문서에서 **사용자가 채워야 할 입력란**을 식별하는 패턴을 정리한다.
> `converter/slot_detector.py`가 이 패턴을 자동 탐지하며, `converter/template_injector.py`가 주입한다.

## 핵심 패턴

### 1. 빈 셀 (empty_cell)
```
| 기업명 |          |  ← 라벨 옆 빈 셀 = 입력란
| 대표자 |          |
```
- **탐지 조건**: 왼쪽 셀에 라벨 키워드(`기업명`, `대표자`, `성명`, `주소` 등) + 오른쪽 셀이 비어있음
- **주입 방법**: `{"type": "cell"}`

### 2. 밑줄/공백 (blank_fill)
```
_______________  귀중
```
- **탐지 조건**: `___` 3개 이상 연속 또는 공백 5칸 이상
- **주입 방법**: `{"type": "t_element"}` 또는 `{"type": "text_replace"}`

### 3. 이름 placeholder (name_placeholder)
```
기업명 :  ㅇㅇㅇ  (인)
대표자 :  ㅇㅇㅇ  (인)
```
- **변형**: `ㅇㅇㅇ`, `ooo`, `OOO`, `000`, `○○○`
- **주의**: 한글 `ㅇ`과 라틴 `o` 모두 사용됨
- **주입 방법**: `{"type": "text_replace", "find": "ㅇㅇㅇ", "replace": "실제이름"}`

### 4. 날짜 입력란 (date)
```
2025년   월   일
20  년   월   일
20   .   .   .자
```
- **탐지 조건**: `년\s+월\s+일` 또는 `20\s+.\s+.\s+.자` 패턴
- **주입 방법**: `{"type": "text_replace"}`

### 5. 콜론 뒤 빈값 (label_empty)
```
신청기업명 :
신  청  자 :             (인)
성  명 :
연  락  처 :
```
- **탐지 조건**: 라벨(`기업명`, `신청자`, `대표자`, `성명`, `연락처`) + `:` + 빈값
- **주입 방법**: `{"type": "text_replace"}`

### 6. 체크박스 (checkbox)
```
☐ 기본진단 (정부지원 80%)
☐ 심화진단 (정부지원 80%)
```
- **주입 방법**: `{"type": "checkbox", "checked": true}` → ☐ → ☑

### 7. 서명란 (signature) — 보통 SKIP
```
(인)    (법인 서명)    (개인 서명)    (법인인감)
```
- **처리**: 이름은 넣되, `(인)` 마크 자체는 유지

## 특수 구조: 한 셀에 여러 입력란

한국 공문서에서 흔한 패턴:
```xml
<hp:tc>  <!-- 하나의 셀 안에 여러 줄 -->
  <hp:t>2025년   월   일</hp:t>         ← t1: 날짜
  <hp:t>신청기업명 : </hp:t>              ← t2: 기업명
  <hp:t>신  청  자 :        (인)</hp:t>   ← t3: 신청자
</hp:tc>
```
→ `text_replace` 또는 `t_element` 타입으로 개별 `<hp:t>` 단위 교체 필요

## Python 자동화 가능성

| 항목 | 자동화 수준 | 비고 |
|------|-----------|------|
| 빈 셀 탐지 | ✅ 완전 자동 | 라벨 키워드 매칭 |
| 밑줄/공백 | ✅ 완전 자동 | 정규식 |
| ㅇㅇㅇ 패턴 | ✅ 완전 자동 | 정규식 |
| 날짜 | ✅ 완전 자동 | 정규식 + 오늘 날짜 |
| 체크박스 | ⚠️ 반자동 | 어떤 걸 체크할지는 비즈니스 로직 |
| 서명 | ❌ 수동 | 실제 서명/인감은 자동화 불가 |
| 입력 데이터 결정 | ⚠️ LLM 보조 | 어떤 값을 넣을지는 컨텍스트 필요 |

**결론**: 슬롯 탐지의 80%+ 는 Python으로 자동화 가능. 나머지는 LLM이 JSON 생성으로 보조.
