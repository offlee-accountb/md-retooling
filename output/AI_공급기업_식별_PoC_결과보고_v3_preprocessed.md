<주제목> AI 공급기업 식별 시범분석 결과 보고

-26.5.12(화) 글로벌AI전문기업실-


□ 추진 배경

□ 「글로벌AI전문기업실」 출범 이후 부서 명칭에 상응하는 **"관리 중 AI 기업 현황"** 의 외부 제시 필요성 증대

 ◦ 현재 공급기업 POOL 등록정보는 기업 자체 기입 "주력분야" 텍스트에 의존, 실제 AI 기술 보유 여부의 객관적 판정 곤란

 ◦ AI 기업과 단순 MES·ERP 공급기업이 구분 없이 혼재, 외부 질의 시 "AI 기업 OO개" 즉답 근거 부재

□ 공식 분류체계(등록 → 역량진단 → 우수 → 전문기업)를 유지하면서, 그 위에 **"AI 특화 메타정보 레이어"** 를 단계적으로 얹는 방식의 첫 단추로 시범분석(PoC) 실시

 ◦ (분석 단위) 기업 단위가 아닌 **솔루션 단위** AI 여부 판정

 ◦ (활용 모델) 내부망 운영 가능한 경량 AI 언어모델(LLM)

 ◦ (성과) 추가 예산 無, 외부 클라우드 미사용, 3주 내 완료

□ 본 PoC의 의의와 한계

 ◦ 의의 ─ 1단계 성과로서의 가치

□ AI 기업 식별 체계 구축 3단계 로드맵 중 **1단계(기존 데이터 재조합, 무비용)** 성과에 해당

 ◦ **(자원 효율성)** 3주, 추가 예산 0원, 외부 인터넷 미사용 환경에서 6,127건 처리

 ◦ **(방법론 입증)** 솔루션 단위 LLM 자동 분류의 실현 가능성 확인

 ◦ **(정량 근거 확보)** 외부 검증 92% 일치율, 도메인 84.6% 일치율로 활용 가능 수준 1차 결과 도출

 ◦ **(공식 체계 침해 無)** 등록 → 진단 → 우수 → 전문기업 기존 분류 유지, 그 위 "AI 여부" 태그만 추가하는 메타데이터 보강 방식


 ◦ 한계 ─ "식별을 시도한 단계"로서의 본질적 제약

□ **(키워드 1차 분류 한계)** "AI 키워드를 적은 기업"과 "실질적 AI 역량 보유 기업"의 분리 불가

   - 본 결과는 "AI라고 주장하는 기업" 식별이지 "AI 역량 보유 기업" 식별이 아님

□ **(자기기입 텍스트 신뢰성)** POOL 등록 텍스트의 30% 부실, 텍스트 기반 판정은 기업의 서술 성실도에 좌우

   - 우수 AI 기술 보유에도 텍스트 부실 시 N 판정되는 false negative 위험 상존

□ **(분류체계 경계 모호성)** 12개 도메인 중 도메인 3·10·11의 사용 빈도 극저(총 13건), 도메인 6/8 "비전 검사" 귀속 등 경계 룰 미정밀

□ **(신뢰도 단일등급 한계)** LLM 자체 확신도와 자동 신뢰도 룰의 일부 불일치(N+H+N 조합 1,624건), 단일 등급으로 외부 제시 곤란

□ **(외부 공표 단계)** 청중별 활용 가능성 차등 적용 필요

□ 시사점

□ **(솔루션 단위 분석의 정합성 입증)** 같은 기업 내 AI/비AI 솔루션 공존 376건(전체 기업 15%) 확인

   - 기업 통째 분류는 실제 현황 왜곡, 솔루션 단위 판정 후 기업 단위 집계가 정합적 기준

□ **(자동 분류의 실효성과 한계 동시 확인)** 6,100건 전수 분류를 3주 완료한 점은 의미 있으나, 도메인 정확 일치율 69%·false negative 5건 확인

   - **"자동 분류 + 전문가 검수" 하이브리드 운영** 이 표준 모델

□ **(데이터 품질 개선의 선행성)** POOL 자기기입 30% 부실은 분류 정확도 차원을 넘어 "POOL이 관리하는 대상의 정보 부재"를 의미

   - 텍스트 보강 없이는 어떤 고도화 모델 도입도 한계 명확

□ **(출발점이지 종착점 아님)** "AI 기업 식별"을 외부에 자신 있게 제시하려면 본 PoC 한계를 정조준한 후속 단계 필수


□ 후속 추진계획

 ◦ 2단계 PoC ─ "키워드 AI"에서 "실질 AI"로 ('26년 하반기)

□ **(목표)** 본 PoC의 "키워드 1차 분류" 한계를 넘어 실제 AI 역량 보유 여부 분리 검증 체계 구축

□ **(우선 보강 영역)**

 ◦ (자기기입 텍스트 보강) POOL 부실 텍스트 752건 대상 외부정보(홈페이지·보도자료·특허) 자동 수집·보강 ← LLM 정보 수집 파이프라인

 ◦ (키워드 vs 실질 분리) AI 판정 1,222건 중 실질 AI 역량 보유 기업 정밀 식별 ← 고성능 모델(Sonnet 4.6·27B Dense급) 활용

 ◦ (도메인 경계 룰 정밀화) 도메인 6/8 경계, 안전·MLOps 흡수 룰 정비 ← 룰북 v0.5 → v1.0 정식화

 ◦ (신뢰도 등급체계 정착) Admiralty 변형 코드(출처·정보 2축) 도입, 기업별 A~D 등급 부여 ← 정보분석 표준 방법론 적용

□ **(기대 산출물)** "AI 기업 후보 리스트 v1.0" (실질 AI 역량 보유 기업 보수적 추정치 + 기업별 신뢰도 등급)

□ **(소요)** 4~6개월, 운영비 소액


 ◦ 3단계 ─ 사업계획서 디지털화 기반 실증 DB 구축 ('27년~)

□ **(목표)** 자기기입 텍스트의 본질적 한계 우회, 이미 외부 평가(감리) 거친 사업계획서 데이터 활용 최고 신뢰도 AI 기업 DB 구축

 ◦ 과거 3~5년치 감리 완료 사업계획서 PDF의 구조화 디지털화

 ◦ AS-IS/TO-BE 텍스트로부터 AI 기술요소·적용 산업·정량 효과 자동 추출

**○ 외부 인용 가능 단락**

Claude SOTA 모델로 본 PoC 결과의 신뢰성 교차검증 수행, Gold Standard 77건 기준 AI=Y/N 일치율 92.0%, 도메인 관대 일치율 84.6% 확인. 9B 모델의 보수적 경향 확인(false negative 5건 vs false positive 1건), 이를 반영한 AI 보유 기업 추정 범위는 21~27%. 식별된 주요 한계로 공급기업POOL 자기기입 텍스트 30% 부실, 도메인 6/8 경계 모호성이 있으며, 후속 PoC에서 텍스트 보강·실질 AI 분리·도메인 정밀화 우선 추진.
