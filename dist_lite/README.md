# 📄 MD → 한글(HWPX) 변환기 - Lite

> 마크다운으로 문서를 작성하면, 한글 파일(.hwpx)로 자동 변환합니다.

---

## 1. 실행 방법

### 방법 A: 실행 파일 (추천 👍)

> **Python 설치 없이** 바로 사용 가능합니다.

1. `MD변환기.exe` 파일을 더블클릭
2. 브라우저가 자동으로 열립니다
3. 마크다운 파일(`.md`)을 **드래그 & 드롭** 하거나 파일 선택
4. **변환하기** 버튼 클릭
5. `.hwpx` 파일이 자동 다운로드 됩니다

> 💡 변환기를 종료하려면 콘솔 창을 닫으면 됩니다.

### 방법 B: Python 직접 실행

#### 필요 환경
- **Python 3.11 이상** ([다운로드](https://www.python.org/downloads/))
- 추가 패키지: `PyYAML`

```bash
# 1) PyYAML 설치 (최초 1회만)
pip install PyYAML

# 2) 웹 변환기 실행
python run_web.py
```

브라우저에서 자동으로 `http://localhost:8080` 이 열립니다.

---

## 2. 사용 방법

1. 브라우저에 마크다운 파일(`.md`)을 **드래그 & 드롭** 하거나 파일 선택
2. **변환** 버튼 클릭
3. `.hwpx` 파일이 자동 다운로드 됩니다

---

## 3. 폴더 구성

```
dist_lite/
├── MD변환기.exe                  ← 더블클릭으로 실행 (Windows)
├── README.md                    ← 지금 읽고 있는 파일
├── 마크다운_작성가이드.md          ← 기존 자료를 MD로 변환하는 방법
├── 예시/
│   └── sample.md                ← 바로 변환해볼 수 있는 예시 파일
├── converter/                   ← 변환 엔진 (수정 불필요)
├── validator/                   ← 스타일 설정 (수정 불필요)
├── templates/                   ← HWPX 템플릿 (수정 불필요)
└── run_web.py                   ← Python 직접 실행 시 사용
```

---

## 4. 주의사항

- 변환 결과는 **한글 2020 이상**에서 열 수 있습니다
- `.hwp` (구형)가 아닌 `.hwpx` (신형) 포맷입니다
- 문제 발생 시 마크다운 파일의 문법을 `마크다운_작성가이드.md`에서 확인하세요
