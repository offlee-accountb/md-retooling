# ✏️ 기존 자료를 마크다운으로 변환하는 가이드

> 이미 작성된 한글/워드 문서를 마크다운(`.md`)으로 옮기는 방법을 안내합니다.
> **AI(ChatGPT/Claude 등)에게 이 가이드와 함께 원본 텍스트를 주면 자동 변환도 가능합니다.**

---

## 기본 원칙

- 한글 파일의 **텍스트를 복사**해서 마크다운 문법으로 감싸면 됩니다
- 서식(Bold, 밑줄 등)은 마크다운이 자동 처리합니다
- 표는 마크다운 표 문법을 사용합니다

---

## 1단계: 제목 변환

한글 문서에서 대제목, 소제목, 항목 등을 아래 규칙에 따라 변환합니다.

### 규칙표

| 한글 문서 | 마크다운 변환 |
|---|---|
| 문서 맨 위 큰 제목 | `# 제목` |
| □ 소제목 | `## □ 소제목` |
| ○ 항목 | `### ○ 항목 내용` |
| 본문 텍스트 | 그냥 줄바꿈하며 입력 |
| **굵은 글씨** | `**굵은 글씨**` |

### 예시

**한글 원본:**
```
Ⅲ. 사업 추진 현황

 □ 예산 현황
  ○ (예산 규모) 총 1,052억원 투입
```

**마크다운 변환:**
```markdown
# Ⅲ. 사업 추진 현황

## □ 예산 현황

### ○ (예산 규모) 총 1,052억원 투입
```

---

## 2단계: 표 변환

표는 `|` (파이프)로 열을 구분합니다. 첫 행은 헤더, 두 번째 행은 구분선입니다.

### 예시

**한글 원본:**
```
구분      예산(억원)    지원기업수(개)
정부단독형   526.6        310
상생협력형   253         1,043
```

**마크다운 변환:**
```markdown
| 구분 | 예산(억원) | 지원기업수(개) |
| --- | --- | --- |
| 정부단독형 | 526.6 | 310 |
| 상생협력형 | 253 | 1,043 |
```

### 합계행이 있는 표

마지막 행이 합계인 경우 `**굵게**` 표시하면 자동으로 합계행 스타일이 적용됩니다.

```markdown
| 구분 | 예산(억원) | 지원기업수(개) |
| --- | --- | --- |
| 정부단독형 | 526.6 | 310 |
| 상생협력형 | 253 | 1,043 |
| **합계** | **1,052.3** | **3,282** |
```

## 3단계: 프로세스 흐름도

업무 절차나 추진 과정을 도식화할 때 사용합니다.

### 규칙

```markdown
<프로세스: 제목>
단계명(담당자) → 단계명(담당자) → 단계명(담당자)
↓
단계명(담당자) ← 단계명(담당자) ← 단계명(담당자)
</프로세스>
```

- `→` : 왼쪽에서 오른쪽으로 진행
- `←` : 오른쪽에서 왼쪽으로 진행 (역방향)
- `↓` : 다음 줄로 이동
- `단계명(담당자)` : 괄호 안이 담당 기관/부서

### 예시

**한글 원본:**
```
< 사업 추진절차 >
① 사업공고(운영기관) → ② 신청접수(전담기관) → ③ 선정평가(전담기관) → ④ 원가계산(원가계산기관)
                                                                          ↓
⑧ 최종감리(전문감리기관) ← ⑦ 중간점검(전문가 자문단) ← ⑥ 솔루션 개발(컨소시엄) ← ⑤ 협약체결(전담기관)
```

**마크다운 변환:**
```markdown
<프로세스: 사업 추진절차>
사업공고(운영기관) → 신청접수(전담기관) → 선정평가(전담기관) → 원가계산(원가계산기관)
↓
최종감리(전문감리기관) ← 중간점검(전문가 자문단) ← 솔루션 개발(컨소시엄) ← 협약체결(전담기관)
</프로세스>
```

> ①②③ 번호는 **자동으로 붙습니다.** 직접 쓸 필요 없습니다.

---

## 4단계: 요약표 (점선 테두리)

핵심 사항을 점선 박스로 강조할 때 사용합니다.

```markdown
<요약표>
| 핵심 | 내용 |
| --- | --- |
| 사업 목적 | 스마트공장 보급 확산 |
| 지원 규모 | 1,052억원 |
</요약표>
```

---

## AI에게 변환 요청하기

아래 프롬프트를 복사해서 AI에게 보내면 자동 변환됩니다:

```
다음 한글 문서 텍스트를 마크다운으로 변환해주세요.
변환 규칙:
- 대제목은 # , 소제목(□)은 ## , 항목(○)은 ### 사용
- 표는 마크다운 표 문법 (| 구분) 사용
- 합계행은 **굵게** 표시
- 프로세스 흐름도는 <프로세스: 제목> 태그 사용
- ①②③ 번호는 넣지 마세요 (자동 부여됩니다)
- 텍스트 내용은 절대 수정하지 말고 그대로 유지

원본 텍스트:
[여기에 한글 파일 텍스트를 붙여넣기]
```

---

## 자주 하는 실수

| 실수 | 해결 |
|---|---|
| 표 구분선 `---` 빠뜨림 | 헤더 아래에 `| --- | --- |` 반드시 추가 |
| 프로세스에 번호 직접 입력 | ①②③ 쓰지 말 것 → 자동 부여됨 |
| 제목 `#` 뒤에 공백 없음 | `#제목` ❌ → `# 제목` ✅ |
| 표 안에 `|` 문자 사용 | 내용에 `|`가 있으면 깨짐 → 피하세요 |
